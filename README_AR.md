# NizarScan — حزمة المشروع التأسيسية (iOS / SwiftUI)

هذه حزمة مصدر أولية لتطبيق iPhone أصلي باسم **NizarScan**. ليست ملف IPA جاهزاً، ولم يتم بعد تنفيذ بناء Xcode على macOS أو اختبار التطبيق على جهاز حقيقي.

## الموجود في هذه الحزمة

- واجهة SwiftUI بأقسام المكتبة وOCR وPDF ومساعد AI.
- مسح المستندات بكاميرا iOS عبر VisionKit.
- حفظ صور الصفحات وفهرس المستندات محلياً داخل التطبيق.
- OCR باستخدام Apple Vision مع إعداد اللغات العربية والألمانية والإنجليزية؛ يجب التحقق من دعم اللغات على إصدار iOS المستهدف أثناء الاختبار.
- تحسين صورة أساسي بالأبيض والأسود/التباين عبر Core Image.
- إنشاء PDF متعدد الصفحات ومشاركته عبر ورقة المشاركة في iOS.
- لوحة لرسم التوقيع وتصديره كصورة PNG.
- اتصال اختياري بخدمة AI متوافقة مع OpenAI Chat Completions. يحتاج مفتاح API من المستخدم وقد يسبب تكلفة لدى مزود الخدمة.
- ملفات ترجمة أولية للعربية والألمانية والإنجليزية؛ الترجمة ليست مكتملة لكل النصوص في هذه النسخة.

## ما لم يكتمل بعد — مهم

- لم يتم دمج التوقيع تلقائياً داخل صفحات PDF؛ الموجود هو رسمه وتصديره كصورة.
- لا توجد مزامنة تلقائية مع iCloud؛ التخزين محلي ويمكن مشاركة ملفات PDF إلى Files/iCloud Drive يدوياً.
- لا توجد بعد أدوات متقدمة لدمج/تقسيم/إعادة ترتيب ملفات PDF موجودة.
- ميزة AI تعتمد على OCR المنفذ أولاً وعلى API خارجي، وليست مجانية بالضرورة.
- لا تعتبر هذه النسخة بديلاً كاملاً عن CamScanner حتى تُستكمل الاختبارات والميزات.

## رفع المشروع من الآيفون إلى GitHub

1. افتح مستودع `https://github.com/iphonesalha-web/NizarScan`.
2. اختر **Add file → Upload files**.
3. فك ضغط `NizarScan-Project.zip` على جهازك أو في تطبيق الملفات، ثم ارفع **محتويات مجلد NizarScan** إلى جذر المستودع، بحيث يظهر `project.yml` و`codemagic.yaml` في المستوى الرئيسي.
4. اضغط **Commit changes**.

إذا لم يسمح متصفح الهاتف برفع مجلد كامل، ارفع ZIP نفسه إلى المستودع أولاً، ثم نستخدم طريقة بديلة لنقل المحتويات؛ Codemagic يحتاج ملفات المشروع في جذر المستودع ولا يستطيع البناء من ZIP غير مفكوك تلقائياً بهذه الإعدادات.

## البناء السحابي لإنتاج IPA غير موقّع

ملف `codemagic.yaml` يعرّف workflow باسم `NizarScan - unsigned IPA for ESign`. بعد ربط المستودع بخدمة Codemagic وتشغيل workflow، يفترض أن ينتج ملف `NizarScan-unsigned.ipa` ضمن Artifacts إذا نجح البناء.

هذا يحتاج macOS/Xcode في خدمة البناء السحابية. توفر الخطة المجانية وحدود دقائق البناء تتغير حسب مزود الخدمة والحساب؛ تحقق من الخطة قبل بدء أي بناء مدفوع ولا تضف وسيلة دفع إلا إذا كنت موافقاً.

## التوقيع عبر ESign

الـ IPA الناتج غير موقّع. بعد تنزيله إلى iPhone، استورده إلى ESign ثم وقّعه بشهادتك وملف provisioning profile المتوافقين. Bundle ID الحالي هو:

`com.nizarsalha.NizarScan`

يجب أن يسمح ملف التوقيع بهذا Bundle ID. لا ترسل في المحادثة ملف P12 أو كلمة مروره أو ملف provisioning profile يحتوي بيانات حساسة أو أي مفتاح خاص.

## بنية المشروع

- `project.yml`: إعداد XcodeGen لتوليد مشروع Xcode.
- `codemagic.yaml`: خطوات البناء السحابي وتغليف IPA غير موقع.
- `NizarScan/`: ملفات SwiftUI وVisionKit وVision وPDF.
- `README_AR.md`: هذا الدليل.

## ملاحظة التحقق

تم فحص محتويات الحزمة وملفات الإعداد محلياً فقط. لم يتم تشغيل Xcode أو إنشاء IPA فعلي في هذه البيئة، لذلك لا أصف البناء بأنه ناجح قبل ظهور نتيجة Build ناجحة من Codemagic.
